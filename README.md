# 🔁 SmartValue — Smart Device Trade-In Platform

A multi-page, responsive landing page built for **SmartValue**, a platform designed to simplify the process of exchanging old devices for newer technology. Designed in **Figma** with a focus on pixel-perfect UI and dark-themed aesthetics, then brought to life using modern React tooling.

---

## 🌐 Live Demo

👉 [apex-landing-page2.vercel.app](https://apex-landing-page2.vercel.app)

---

## 🛠 Tech Stack

| Technology | Purpose |
|---|---|
| React 18 + TypeScript | Core framework |
| Vite | Build tool and dev server |
| Tailwind CSS | Utility-first styling |
| shadcn/ui | Accessible component library |
| Framer Motion | Scroll and load animations |
| React Leaflet | Interactive store locator map |
| React Hook Form + Zod | Form validation |
| React Router DOM | Client-side routing |

---

## ✨ Features

- 🎬 Hero section with smooth load animations
- 📋 Schedule a Demo popup modal with form
- 🎭 Scroll-triggered animations across all sections
- 🗺 Store Locator with live map and city-based search
- 📱 Interactive How It Works stepper
- 🌏 Bilingual support — English and Hindi
- 🪟 Glassmorphism navbar with scroll-aware background
- 📬 Contact form with office image and location details
- 📐 Fully responsive design for all screen sizes

## 🚀 Getting Started

**Clone the repository:**
```bash
git clone https://github.com/ANUSHREE-CYBER/Apex-Landing-Page2.git
```

**Install dependencies:**
```bash
npm install
```

**Start the development server:**
```bash
npm run dev
```

Open your browser at `http://localhost:8080`
